\# AWS Three-Tier Architecture Project



\## Project Overview

This project demonstrates an AWS Three-Tier Architecture for hosting a Student Application. It separates the application into different layers to improve security, scalability, and maintainability.



\## Architecture Layers



1\. \*\*Presentation Layer\*\* – Handles user access to the application.

2\. \*\*Application Layer\*\* – Runs the application using Apache Tomcat on an EC2 instance.

3\. \*\*Database Layer\*\* – Stores application data using Amazon RDS with MariaDB.



\## AWS Services Used



\- Amazon VPC

\- Public and Private Subnets

\- Internet Gateway (IGW)

\- NAT Gateway

\- Route Tables

\- Amazon EC2

\- Security Groups

\- Amazon RDS (MariaDB)

\- Apache Tomcat



\## Project Implementation



\- Created a VPC and configured public and private subnets.

\- Configured Internet Gateway, NAT Gateway, and route tables.

\- Configured security groups for controlled network access.

\- Set up EC2 instances for application access and administration.

\- Configured Apache Tomcat for the Student Application.

\- Used Amazon RDS with MariaDB for the database layer.
